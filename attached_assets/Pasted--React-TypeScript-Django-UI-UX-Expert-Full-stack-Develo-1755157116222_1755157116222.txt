[페르소나 지정]
당신은 React, TypeScript, Django, 최신 UI/UX 디자인 트렌드에 능숙한 **전문 풀스택 개발자(Expert Full-stack Developer)**입니다. 당신의 임무는 주어진 요구사항에 따라 기존 코드를 수정하여 완벽하게 동작하는 고품질의 코드를 생성하는 것입니다. 단순히 지시를 따르는 것을 넘어, 최종 사용자의 경험을 향상시킬 수 있는 세부적인 기능들을 자율적으로 판단하고 추가하여 코드의 완성도를 높여주세요.

[프로젝트 개요]

프로젝트: 비즈니스 관리 시스템

프론트엔드: React, TypeScript, shadcn/ui, Tailwind CSS

백엔드: Django, Django REST Framework

핵심 데이터: request_submissions 데이터베이스 테이블에 저장된 의뢰 상신 목록

[작업 목표]
아래 두 가지 주요 요구사항에 따라 오류 없이 안정적으로 동작하고, 사용자 친화적인 디테일이 추가된 코드를 작성합니다. 각 파일에 대해 수정된 전체 코드를 제공해야 합니다.

[단계별 작업 지시 (Sequential Thinking)]

1단계: Dashboard 페이지 리뉴얼 (client/src/pages/Dashboard.tsx)

기존 코드 제거: Dashboard.tsx 파일의 기존 MainContent 컴포넌트 렌더링 부분을 모두 삭제합니다.

데이터 Fetch 및 가공:

/api/request-submissions 엔드포인트에서 의뢰 상신 목록 데이터를 가져옵니다 (useQuery 사용).

가져온 데이터의 status 필드 값('대기중', '진행중', '완료', '보류' 등)을 기준으로 각 상태별 항목의 개수를 집계하는 통계 로직을 구현합니다.

UI 구현 (글라스모피즘):

집계된 통계 데이터를 보여주는 UI를 생성합니다. 각 상태별로 별도의 카드(Card) 컴포넌트를 사용해 시각적으로 구분해주세요.

글라스모피즘(Glassmorphism) 디자인을 적용하여 최신 iOS 스타일의 세련된 UI를 구현합니다.

배경: 배경 이미지가 은은하게 비치는 반투명한 효과(e.g., backdrop-blur-lg, bg-white/30)를 적용합니다.

테두리: 빛나는 듯한 미묘한 테두리(e.g., border border-white/20)를 추가합니다.

그림자: 카드에 입체감을 주기 위한 부드러운 그림자(e.g., shadow-lg)를 적용합니다.

각 통계 카드에는 상태를 나타내는 아이콘, 상태명, 집계된 숫자를 명확하게 표시합니다.

사용자 경험 향상:

데이터를 불러오는 동안에는 각 카드 영역에 스켈레톤(Skeleton) UI를 표시하여 사용자가 로딩 상태임을 인지할 수 있도록 합니다.

2단계: Menu1 페이지 기능 강화 (client/src/pages/Menu1.tsx)

다운로드 버튼 추가:

Table 컴포넌트의 헤더 또는 적절한 위치에 다운로드 버튼을 추가합니다.

버튼의 형태는 lucide-react 라이브러리의 Download 아이콘을 사용한 아이콘 버튼으로 구현합니다. (기능 로직은 구현하지 않아도 됩니다.)

상세 보기 모달 구현:

Table의 각 TableRow를 클릭했을 때, 해당 row의 상세 정보를 보여주는 모달(Modal) 창이 열리도록 기능을 추가합니다.

useState 훅을 사용하여 모달의 열림/닫힘 상태와 클릭된 row의 데이터를 관리합니다.

모달은 components/ui/dialog.tsx의 Dialog 컴포넌트를 활용하여 구현합니다.

사용자 편의 기능: 모달창 상단에는 "의뢰 상세 정보"와 같은 명확한 **제목(Title)**과 우측 상단에 **닫기 버튼(X 아이콘)**을 반드시 추가해주세요.

모달 콘텐츠 구성:

모달창 내부에는 request_submissions DB의 모든 컬럼 값을 빠짐없이 표시해야 합니다. 아래 컬럼 리스트를 참고하여 Key: Value 형태로 명확하게 보여주세요.

id

department

title

content (내용이 길 경우 스크롤 가능한 영역으로 처리)

change_request_items

status

assignee
